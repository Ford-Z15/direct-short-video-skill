## 使用范围

用于短视频脚本的首句、首个画面和开篇承诺。钩子负责让目标观众立即识别「这和我有关，而且值得继续看」；类型模板负责组织后续内容。不得把主题句、书面标题式表达或安全免责声明误认为钩子。

## 通用钩子设计

## HOOK-001｜先完成观看识别，再介绍主题

- **方法**：开篇首先回答观众三个问题：在对谁说、发生在什么场景、继续看能得到什么。至少落实其中两个，再进入类型结构。
- **编导动作**：分别写出目标人群、具体场景和观看理由；删除「大家好」「今天讲一个话题」等只宣布主题、不提供观看理由的句子。
- **边界**：钩子不是夸张标题，不承诺爆款、收益、维修效果或其他无法证明的结果。

## HOOK-002｜从真实素材生成三个不同机制的候选

- **方法**：先写不带技巧的普通表达，再从画面、利益、风险、反差、责任归因、优势或真实疑问中选择不同机制，生成少量候选。
- **编导动作**：优先使用有真实素材、能被正文兑现、能配对应画面的一条；不要为了显得犀利而编造观众误区、行业秘密或冲突。
- **边界**：「很多人不知道」「只有内行懂」等表达必须有事实依据；没有依据时直接说具体对象、场景和用途。

## HOOK-003｜按内容类型选择钩子，不全套一种句式

| 内容类型 | 优先钩子 | 后文必须兑现 |
|---|---|---|
| 推荐 | 人群＋用途／真实信息差 | 推荐对象及各自适用场景 |
| 解题 | 具体困扰＋方法预告 | 方法步骤与真实示例／演示 |
| 盘点 | 对象＋范围／统一标准 | 逐项信息与简短说明 |
| 避坑 | 具体错误＋真实风险 | 每个错误对应的替代做法 |
| 热点 | 事件一句话＋与目标人群的关系 | 事实、缘由／影响／立场的准确展开 |
| 手艺过程 | 成果、罕见动作或真实声音画面 | 关键动作、变化和结果 |
| 观点 | 争议场景＋明确态度 | 一致立场与有效论据 |
| 销售 | 最有证据的优势／真实场景问题 | 卖点证据、使用条件与真实行动方式 |

- **使用**：同一条只选一个主钩子机制；数量、身份、对比和结果必须真实。

## 钩子类型

## HOOK-004｜具体画面型

- **方法**：把抽象问题换成能看见的动作、物件、环境或结果，让观众立即进入现场。
- **编导动作**：圈出「严重、危险、专业、着急」等抽象词，改写成已有资料能支持的细节；首句和首个画面尽量指向同一细节。
- **边界**：没有真实细节时标为待补，不用虚构事故、客户、数字或经历制造画面。

## HOOK-005｜美好愿景与具体利益型

- **方法**：从目标观众真实想获得的结果出发，把愿望写成具体用途、状态或可执行收获。
- **编导动作**：说明正文如何帮助观众靠近这个目标；优先讲清方法、选择或判断，不直接保证结果。
- **边界**：不虚构收益、疗效、成交、节省金额或人人适用的效果。

## HOOK-006｜负面后果与避坑型

- **方法**：指出一个真实错误及其可能后果，同时预告可执行的替代方案。
- **编导动作**：采用「具体错误／风险 → 正确做法」的兑现关系；后果只写资料支持的损害或不便。
- **边界**：不恐吓、不夸大灾害，不把低概率事件写成必然；只指出问题而不给解决方法，不算完整避坑结构。

## HOOK-007｜颠覆认知与观念对立型

- **方法**：当有可靠依据时，用「常见理解 A → 更准确的判断 B」形成反差；也可呈现两种真实选择之间的冲突。
- **编导动作**：紧随钩子给出依据或论证，保证全篇服务对象和立场一致。
- **边界**：不把个别经验写成普遍规律，不制造性别、地域、职业或群体敌意，不为了反对而反对。

## HOOK-008｜责任归类型

- **方法**：当观众把问题归因于错误对象时，基于事实指出真正需要负责或需要检查的环节。
- **编导动作**：写清常规归因、证据和重新归因；把「找人背锅」只当作内部发散提示，公开表达使用可证明的责任分析。
- **边界**：不得甩锅、诽谤、攻击个人或逃避自身责任；事实不清时不做责任判定。

## HOOK-009｜最强优势与真实疑问反转型

- **方法**：销售或展示内容可优先呈现最有证据的功能、设计、使用变化或真实交易条件；也可从观众确实存在的疑问出发，再展示核实过程。
- **编导动作**：先列候选优势与证据，再决定开篇；质疑型必须写清疑问依据、验证过程和结论。
- **边界**：不编造「打假」「千万别买」、使用体验、价格、库存或促销；产品确有限制时不得强行反转成全盘推荐。

## HOOK-010｜句式、情绪和首个画面协同

- **方法**：比较疑问、肯定和否定表达，选择信息最明确且符合出镜者真实态度的一种；用动作强度、真实语言、描述、类比或对比增强表达。
- **编导动作**：让首个画面承担展示问题、成果、动作或证据的任务；字幕只强化重点，不重复堆砌整段口播。
- **边界**：「否定句强于肯定句」只是开篇经验，不是普遍定律；不得用辱骂、夸张或无关危险画面提高情绪。

## 类型匹配与验收

## HOOK-011｜钩子必须被正文逐项兑现

- **方法**：开篇承诺「三件事」「一个方法」「一个对比」时，正文必须按相同数量和顺序交付；主体结束后再收束或给真实下一步。
- **编导动作**：建立「钩子原文 → 对应段落 → 事实／素材 → 画面」映射；删除正文无法证明的承诺。尾钩只用于确有后续价值的内容，不能替代本条完整性。
- **边界**：不用「别划走」「看到最后有惊喜」等空泛挽留，不让结尾成为唯一有价值的信息。

## 开篇验收

- [ ] 首句是否在对明确的人、场景或问题说话，而非只宣布主题？
- [ ] 是否给观众一个具体、可信的继续观看理由？
- [ ] 钩子类型是否与后续脚本结构匹配？
- [ ] 首句与首个画面是否共同表达同一重点？
- [ ] 正文是否按承诺的数量和顺序兑现？
- [ ] 是否删除虚构误区、恐吓、虚假质疑、无关对立和结果保证？
