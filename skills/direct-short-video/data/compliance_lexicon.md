# 违禁与高风险词库说明

## 用途

这是文案初审工具，不是“出现即违规”的静态黑名单。机器可执行词库为 `data/compliance_lexicon.json`，审查流程为 `prompts/compliance_review.md`。

- **review**：必须结合语境、行业和完整语义复核。
- **needs_evidence**：需要有效证据；无法提供时删除。
- **block_in_promotion**：在对应商业推广场景中不得作此承诺或宣传，但仍需先确认行业和语境。

## 当前覆盖

1. 绝对化与最高级宣传。
2. 普遍效果与结果保证。
3. 权威、授权与资质。
4. 医疗、健康与疾病功效。
5. 教育培训结果承诺。
6. 投资、招商与收益承诺。
7. 房地产升值与位置误导。
8. 价格、库存与活动真实性。
9. 数据、研究与证明材料。
10. 服饰材质与功能承诺。
11. 私下交易与不当导流。
12. 贬低竞品与他人。

词库中的词语只是风险线索，完整语义审查不可省略。例如：“第一步打开相机”是正常步骤；“全网第一品牌”是商业宣传风险。“官方账号”也要核对是否真的获得相应授权，而不是简单替换成同义词。

## 使用方式

在项目根目录运行：

```bash
python scripts/check_copy.py "<待检查文案文件路径>"
```

脚本进行 Unicode NFKC 规范化和字面匹配，输出命中词、类别与处理级别。它不会自动改稿，也不会把“未命中”判为“合规”。

机器检查后仍需：

1. 阅读完整句子，排除步骤、顺序等正常语境。
2. 核查证据、适用条件和有效期。
3. 检查同义表达、暗示、画面和字幕。
4. 按发布时目标平台及行业最新官方规则复核。

## 维护规则

- 复核日期记录在 JSON 的 `reviewed_on`。
- 新增词条必须归类并给出处理动作和依据。
- 优先采用法律、监管机构和目标平台官方规则，不把第三方“违禁词大全”直接导入。
- 特别行业规则优先于通用经验；旧规则与现行规则冲突时，先停用旧条目再复核。
- 无法确认现行有效性时标记“未实时核验”，不得声称完整或保证过审。
