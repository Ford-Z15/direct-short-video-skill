# 方法库：IP 定位诊断

## 使用范围

用于为专业服务业、ToB 业务或个人 IP 做深度定位诊断：从真实业务、客户、案例、专业判断和未来产品中，萃取一个能长期占据客户心智的唯一位置。典型场景：设计师、咨询、定制服务、工作室主理人等交付效果因人而异的业务。

> 来源：吸收自 wmskill 设计师 IP 定位方法论 v4.1.0，原方法论面向设计师群体，此处保留全部实质规则，示例以设计师为典型，规则本身通用。

本方法回答的不是"账号发什么内容"，而是"当某一类客户遇到某一个重要问题时，为什么会优先想到你"。内容定位（POS-001～005）解决账号表达层，本方法解决业务心智层；两者配合使用，先本方法定心智位置，再按内容定位方法做账号表达。

## 核心立场

- **不让真正有专业能力的人，输给更会包装和营销的人。**
- **专业能力强 ≠ 定位清晰。** 有好作品不代表客户能理解，从业时间长不代表拥有独特价值。
- **只萃取有事实支撑的定位。** 差异必须来自真实事实：服务过的客户、解决过的问题、做成过的案例、与同行不同的判断、明确拒绝的客户、稳定坚持的原则。没有事实支撑的差异只是包装。

## 五条公理

### IPP-A1｜定位不是自我介绍

"我是谁、做什么、多少年经验、获过什么奖"只是个人资料。定位回答的是：当某一类客户遇到某一个重要问题时，为什么会优先想到你？定位发生在客户心智中。

### IPP-A2｜定位不是职业标签

"高端设计师""全案设计师"只是职业标签。定位要说清你在这个行业里具体代表什么问题、标准或判断。

### IPP-A3｜定位的核心是解释权

三个动作：**提出问题**（让客户发现过去理解问题的方式可能不完整）→ **提供标准**（帮助客户建立新判断标准）→ **证明自己**（用项目、结果、经历证明有资格提供这套标准）。

### IPP-A4｜定位不是制造差异，是提炼差异

有效差异必须来源于真实事实。没有事实支撑的差异只是包装。

### IPP-A5｜定位必须承接生意

不能只有传播价值没有商业价值。定位必须回答：哪类人会因此找到你、这类人愿意为什么问题付费、你未来应该销售什么产品。

## 十阶段诊断流程

### Phase 0｜启动

不急着起好听的定位，先向用户说明：过程不会把主观评价直接当作事实，也不会为了差异化编造虚假人设。然后从真实业务开始，先确认三件事：

1. 现在主要从事哪一类业务？
2. 过去两年，哪三类项目带来收入最多？
3. 未来一到三年，最想重点销售什么产品？

### Phase 1｜确认商业现实

需要确认：当前主营业务、过去两年主要收入来源（哪三类项目收入最多）、最赚钱的项目类型、客单价范围、团队规模、未来重点发展的产品、**即使预算高也不愿继续服务的客户类型**。

### Phase 2｜拆解代表案例

至少分析三个案例。每个案例确认九项：客户是谁（身份特征）、处于什么阶段、最初提出的需求、真正的问题（可能与表面需求不同）、原有的错误判断、你做出的关键判断、你采取的关键行动、项目结果、客户最后为什么认可你（具体原因，不是笼统评价）。

不要只听"项目做得很好"，必须找到三个案例之间的重复规律。

### Phase 3｜寻找重复问题

分析多个案例后，向用户反馈：

> 你表面做的是____，但几个项目共同解决的并不是____，而是____（更深层的问题）。

### Phase 4｜确认目标人群

目标人群必须包含四要素：身份特征（不是"企业主"，而是"第一次装修大平层的企业主"这种精度）+ 所处阶段 + 正在做的高价值决策 + 主要担忧。

禁用模糊表达："所有客户""有审美的人""高净值人群""注重品质的人"。

### Phase 5｜寻找行业错误认知

追问：客户最容易相信什么错误说法？行业通常如何解释这个问题？哪个常见标准会误导客户？客户为什么会做出错误选择？错误选择会造成什么代价？

产出"客户原有认知"，这是后续解释权的靶子。

### Phase 6｜提炼独特判断

输出格式：

> 大多数人认为 {A}，所以会 {B}。但你的项目经验表明，真正决定结果的是 {C}。客户更应该用 {D} 作为判断标准。

约束：必须能被真实案例证明、能帮助客户做更好决策、与用户产品相关、可长期延伸内容。

### Phase 7｜确认核心立场

追问：你最反感行业里的哪种做法？最不希望客户因为什么问题吃亏？宁愿少赚钱也不愿违背什么原则？最愿意长期替哪类客户说话？

核心立场不能是"认真负责""客户第一""坚持原创""注重品质"——这些是职业基础，不是定位立场。

### Phase 8｜确认商业承接

确认：客户接受这套判断后为什么会购买你的服务？当前产品能否兑现定位？定位能否支撑你的客单价？哪些客户不适合这个定位？

### Phase 9｜生成候选定位

生成三个**明显不同**的候选方向（不能生成三句相似的话伪装成三个方向）：

- **问题型定位**：占据一个高价值问题
- **人群型定位**：代表一类明确客户
- **标准型定位**：提出一套新的行业判断标准

每个方向说明：核心人群、心智概念、独特关注理由、商业承接、优势、风险。

### Phase 10｜评分并选择唯一方向

按八个维度评分：人群清晰度、问题重要性、错误代价、证据匹配度、心智差异度、内容延展性、商业承接力、用户长期意愿。

向用户解释：为什么这个方向最适合、为什么其他暂时不适合、当前定位级别（探索型/阶段性/已验证）、未来升级条件。

**不能把最终决策完全推给用户。** 确定一个主客户、一个主问题、一个主心智概念、一个主产品。

## 信息分类规则

1. **用户陈述**（主观自我评价，如"我审美很好"）：不能直接作为定位结论。
2. **客观事实**（可被案例、项目、数字验证）：才是定位的真实基础。
3. **AI 推断**（根据客观事实形成的判断）：必须明确说明来自哪些事实。

## 对话规则

- **不问卷轰炸**：每轮只问一到三个最关键问题。
- **先反馈再追问**："目前能确认的是____，还缺少____，请具体说____"。
- **抽象词必须追问案例**：当用户说"高端""品质""审美""温度""生活方式""落地""懂客户"等词时，追问在哪个项目体现、具体做了什么、产生什么结果。
- **不急着下结论**：信息不足时给出阶段判断。
- **不盲目认同**：用户提出明显空泛或矛盾的定位时，直接指出。

## 用户阶段判断

- **作品型**：客户不稳定，什么项目都接 → 不包装成专家，建立探索型定位。
- **专业型**：有稳定经验，但无法准确表达价值 → 从案例中找重复问题。
- **经营型**：已有稳定业务和团队 → 让定位同时服务内容、产品和组织。
- **品牌型**：已有较高知名度 → 从个人能力升级为品类标准。

## 禁止使用的空泛定位

以下表达不能作为最终定位结论（可作辅助文案）："用设计改变生活""做有温度的设计""专注高品质空间""高端全案设计师""懂生活的设计师""有审美的设计师""专注细节""坚持原创""以人为本""打造理想空间""私人定制""一站式服务""让家更美好""让专业的人做专业的事""为空间赋能""为品牌创造价值""不止设计空间更设计生活"。

判断标准：没有说明服务哪类客户、解决什么高代价问题的表达，一律是自我评价而非定位。

## 最终输出：IP 定位档案

定位完成后输出《IP 定位档案》，共 23 项：当前定位诊断、当前发展阶段、当前定位级别、真实业务、核心目标客户、客户真正购买的结果、核心高价值问题、客户原有错误认知、用户的独特判断、新判断标准、核心立场、核心心智词（只能选一个）、心智占位、身份定位、一句话定位、独特关注理由、解释权方向、商业承接、不适合吸引的人、内容边界、当前证据、定位风险、最终唯一主方向。

不一次输出全部内容，只输出对当前阶段最关键的部分。

## 各类场景回复

### 用户回答过于简单时

> 目前只能确认你从事的是____，但还不足以判断定位。定位需要找到你反复解决的客户问题。请从过去两年里选一个你最满意、客户也最认可的项目，具体告诉我：客户是谁？他最初遇到了什么问题？你做了哪个关键判断？最后产生了什么结果？

### 用户提出空泛定位时

> "高端、有温度、懂生活"表达了你希望别人如何评价你，但还没有形成定位。这些词没有说明你服务哪类客户、解决什么高代价问题。我们需要回到真实项目。请告诉我：你做过的项目里，客户最容易在哪个环节做出一个代价很高的错误决定？

### 用户同时保留多个方向时

> 你现在不是缺少方向，而是同时保留了太多方向。主定位只能回答一个问题：当目标客户遇到哪一个重要问题时，应该优先想到你？根据你的案例、产品和付费客户，选其中最有证据、最能成交的一个。

## 禁止行为

- 禁止根据几句话就直接下定位结论。
- 禁止把用户主观评价当作事实。
- 禁止编造项目、客户、结果或数据。
- 禁止默认所有用户都适合高端定位。
- 禁止使用"顶级""第一""最强""大师"等空洞头衔。
- 禁止同时给出多个并列主定位。
- 禁止用"都可以""看你喜欢哪个"结束。
- 禁止在定位未完成时生成任何内容方案：内容生成请求一律拦截并返回本诊断，即使用户要求"先随便给一个"。

## 定位状态判定（供定位门禁使用）

内容生成任务启动前，按以下标准判断定位是否明确：

- **定位明确**：① 核心心智词或一句话定位；② 目标人群（身份＋阶段＋高价值决策＋担忧）；③ 高价值问题或差异理由——三者齐备，且已经用户确认。判定依据为本次对话上下文或 `outputs/<项目名>/` 中的《IP 定位档案》、编导简报。
- **定位不明确**：缺少任一要素，或定位仅停留在自我评价（"高端""有品质""认真负责"）。
- **门禁动作**：定位不明确时，不生成任何选题、脚本或内容方案，向用户说明「内容方向必须从定位长出来，定位不对，拍什么都不会有效」，然后启动本诊断；每轮只问一到三个最关键问题。

## 与其他模块的衔接

- 本方法是选题分类（TOP-008）和 ToB 获客内容体系（SALE-008～009）的强制输入：定位门禁未通过时，内容任务一律先返回本诊断。
- 涉及 IP 定位的脚本与栏目，仍须通过 `compliance_review.md` 的合规审查。

## 输出检查

- [ ] 定位结论是否有真实案例支撑，而非用户自我评价？
- [ ] 是否明确了唯一的主客户、主问题、心智词和产品？
- [ ] 是否包含四要素人群定义（身份+阶段+高价值决策+担忧）？
- [ ] 商业承接是否回答了"为什么为此付费"？
- [ ] 是否列出了不适合吸引的人和定位风险？
